# Portfolio DroGone

Portfolio professionnel de Robin / DroGone, étudiant en BUT Réseaux & Télécommunications.

Le site présente les domaines réseau, Linux, virtualisation, cloud, supervision et développement à travers une interface inspirée des topologies et des outils d’observabilité.

## Développement

```bash
npm install
npm run dev
```

## Vérification

```bash
npm run lint
npm run build
```

## Technologies

- React + TypeScript + Vite
- Motion
- Lucide React
- CSS responsive sur mesure

Le déploiement GitHub Pages est automatisé à chaque changement sur `main`.
